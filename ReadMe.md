# Home Key

As part of the **"Développeur web et web mobile"** training at **La Plateforme**, this project consists of reproducing a website integration using only **HTML** and **CSS**.

The main objective of this project was to practice layout creation exclusively with **Flexbox**, without using **CSS Grid**.

## Technologies Used

- HTML5
- CSS3
- Flexbox
